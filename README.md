# sheetu-woocommerce-wordpress
Custom WooCommerce frontend theme built by a frontend developer.

## Features
- WooCommerce integration
- Product archive & single product templates
- Responsive frontend layout
- Clean WordPress theme structure

## Tech Stack
- HTML
- CSS
- JavaScript
- WordPress
- WooCommerce

## Installation
1. Upload to `/wp-content/themes/`
2. Install WooCommerce plugin
3. Activate theme
